# 카탈로그 관계 검증

## 검증 범위와 결과

- 컬렉션: 6개
- 현재 제품 패밀리: 27개
- 현재 마감 변형: 37개
- 발견한 원본 제품 이미지: 37개
- 정규화한 실제 이미지: 37개
- 고객 화면에 연결한 실제 이미지: 36개
- 모호하여 플레이스홀더를 유지한 변형: 1개

수량이 일치한다는 사실만으로 현재 카탈로그 구조가 사업적으로 검증된 것은
아니다. 아래 판단은 원본 파일명과 이미지 외형만을 근거로 하며 제품 관계를
임의로 변경하지 않았다.

## 관계별 검토

### HG110-1, HG110C, HG110S

- 현재 구현: 세 개의 별도 제품 패밀리이며 서로 관련 제품으로 연결됨.
- 증거: HG110-1은 정면 플레이트와 휴지 투입부 형상이 HG110C/S와 명확히
  다르다. HG110C와 HG110S는 유사한 구성이나 파일명과 이미지 내부 표기에
  서로 다른 모델 번호가 있다.
- 위험: HG110C/S가 한 설계의 마감별 모델인지 별도 판매 단위인지 파일만으로
  확정할 수 없다.
- 권장 확인: 각 모델이 독립 상세 페이지를 가져야 하는지, C/S가 공식적으로
  크롬/사틴을 뜻하는지 확인한다. 확인 전에는 현재처럼 합치지 않는다.

### HG112C, HG112S

- 현재 구현: 크롬 HG112C와 사틴 HG112S가 각각 별도 제품 패밀리임.
- 증거: 두 이미지의 정면 플레이트와 트레이 구성은 유사하고 파일명은 서로
  다른 모델 번호와 마감을 명시한다.
- 위험: 고객은 한 제품의 마감 선택으로 기대할 수 있으나 실제 판매 모델이
  분리되어 있을 수 있다.
- 권장 확인: 한 패밀리의 마감 변형으로 합칠지, 모델별 독립 페이지를 유지할지
  사업자가 결정해야 한다. 현재 모델 관계를 유지했다.

### HG513

- 현재 구현: HG513 한 패밀리에 `미확인`과 `사틴` 두 변형이 있음.
- 증거: 두 이미지는 같은 제품 구성과 유사한 각도지만 손잡이와 본체 표면이
  다르게 보인다. 한 파일은 `사틴`, 다른 파일은 마감 정보가 없다.
- 위험: 마감 미표기 이미지가 다른 마감, 이전 사진, 또는 단순 대체 이미지인지
  확정할 수 없다.
- 권장 확인: 마감 미표기 이미지의 공식 마감명과 판매 변형 여부를 확인한다.
  `사틴` 이미지만 고객 화면에 연결했고 `미확인` 변형은 플레이스홀더를
  유지했다.

### HG999, HG999-2

- 현재 구현: 별도 제품 패밀리.
- 증거: 거울 형상은 유사하지만 벽체 지지부와 암 구성이 다르고 모델 번호도
  다르다.
- 위험: 이름이 같다는 이유로 합치면 다른 설치 구조를 하나의 변형으로 잘못
  표현할 수 있다.
- 권장 확인: 별도 모델과 설치 방식임을 확인한다. 확인 전에는 합치지 않는다.

### HG820, HG822C, HG822S

- 현재 구현: HG820은 별도 패밀리, HG822는 크롬·사틴 변형을 가진 한 패밀리.
- 증거: HG820과 HG822는 선반 형상이 다르다. HG822 원본은 각각 HG822C와
  HG822S 모델명을 명시한다.
- 위험: 기존 데이터는 두 HG822 변형 모두 모델 번호를 `HG822`로 표시했다.
- 적용: 제품 패밀리는 유지하고 변형 표시 모델만 `HG822C`, `HG822S`로
  정정했다.
- 권장 확인: HG822가 공식 패밀리명인지, C/S 모델을 독립 판매 페이지로
  분리해야 하는지 확인한다.

### `무광` 표기 제품

- 현재 구현: HG01MS, HG100MS, HG392MS의 마감을 `무광`으로 표시함.
- 증거: 세 원본 파일명이 모두 `(무광)`을 포함한다.
- 위험: `무광`이 공식 마감명인지 촬영 파일을 구분하기 위한 내부 표현인지
  확인되지 않았다.
- 권장 확인: 공식 마감 명칭과 다른 마감과의 구분 기준을 확인한다. 현재는
  원본의 한국어 표기를 그대로 유지한다.

### 바투타·벨레어·브리오·사코·콩코드

- 현재 구현: 각 컬렉션에 수건걸이와 휴지걸이를 묶고, 파일명에 기재된 마감을
  변형으로 연결함.
- 증거: 모든 수건걸이/휴지걸이 파일은 제품 형상과 마감을 구분할 수 있다.
- 위험: 아래 세 쌍은 SHA-256 해시가 동일한 완전 중복 파일이다.
  - 바투타 사틴 휴지걸이 = 벨레어 사틴 휴지걸이
  - 브리오 사틴 휴지걸이 = 콩코드 사틴 휴지걸이
  - 브리오 크롬 휴지걸이 = 콩코드 크롬 휴지걸이
- 적용: 파일명대로 연결했으며 제품 관계나 명칭을 변경하지 않았다.
- 권장 확인: 완전 중복 파일이 올바른 제품 사진인지 원본 제공자에게 확인한다.

## 이미지 자체의 추가 확인 사항

- HG 이미지에는 `HOYANG` 표식이 포함되어 있다. 최종 브랜드명, 이미지 사용
  권한, 사이트 브랜드와 이미지 내 표식의 관계를 출시 전에 확인해야 한다.
- HG392MS 이미지에는 치수 표기가 포함되어 있지만 별도 검증 전까지 사양
  데이터로 전사하지 않았다.
- HG 원본은 대체로 447~795픽셀로 명명 컬렉션 이미지보다 해상도가 낮다.
  업스케일하지 않았으며 확대 화면 품질을 확인할 고해상도 원본이 필요하다.
- 모든 원본의 방향값은 정상이다. 제품 외곽을 침범하지 않는다고 확신할 수 없는
  자동 크롭은 적용하지 않았다.

## 유지한 가정

- 제품의 `available: false`와 빈 `naverUrl` 상태를 유지한다.
- 파일명으로 확인되지 않는 치수, 재질, 설치법, 보증, 인증, 가격은 추가하지
  않는다.
- `confirmed-from-filename`은 사업 검증이 아니라 파일명과 이미지가 서로
  일치한다는 뜻이다.
